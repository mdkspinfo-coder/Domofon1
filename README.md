

## Как поставить на iPhone

1. Открой адрес сайта в **Safari** (не в Chrome).
2. Разреши доступ к геолокации (лучше «При использовании»; в Safari можно поставить «Всегда для этого сайта»).
3. Кнопка «Поделиться» → «На экран „Домой“». Иконка появится как у обычного приложения.

## Как пользоваться

- «＋ Добавить домофон» → наведи прицел на дом → «Поставить здесь» → введи пароль.
- Серый маркер: далеко, нажатие покажет расстояние. Зелёный: ближе 800 м, нажатие покажет код.
- «◎» возвращает карту к тебе. 3D-здания включаются сами, когда карта находится в Польше.

## Проверки

```bash
node --test tests/geo.test.js        # логика радиуса 800 м и границ Польши
python3 tests/ui_test.py             # прогон интерфейса в Chrome (нужны playwright и Chrome)
```

`ui_test.py` подменяет GPS и заменяет библиотеку карты заглушкой, поэтому проверяет интерфейс и правила показа кода,
но не отрисовку карты и 3D. Это нужно один раз проверить на реальном телефоне.

## Ограничения

- GPS в вебе работает, пока страница открыта на экране телефона. В фоне и при заблокированном экране позиция не обновляется.
- Данные лежат в браузере телефона (localStorage). Если очистить данные сайта Safari или удалить иконку, маркеры пропадут.
  Код хранится открытым текстом на устройстве: защита от показа «вдали» это удобство, а не шифрование.
  Safari может очищать данные сайтов, которыми давно не пользовались.
- Маркеры не синхронизируются между устройствами. Для этого нужен бэкенд и аккаунты.
- Бесплатные тайлы OpenFreeMap подходят для личного использования; для большой аудитории нужен свой сервер тайлов или платный провайдер.
